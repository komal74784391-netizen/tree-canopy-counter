# Tree Canopy Counter

Status: **Released** - v0.9.2 (2026-10-01)

Edge-oriented segmentation utilities for estimating urban tree canopy cover from
small image tiles.  The package is designed to run on constrained devices.

## Layout

- `src/canopy_counter/segment.py` - tile segmentation and coverage estimate
- `data/sample_tiles/` - sample tile manifest
- `experiments/eval_notes.md` - evaluation notes on the holdout quadrats
